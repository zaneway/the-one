# Claude Code × The One（P4）

## 前置

1. 仓库根目录执行：`go build -o bin/theone ./cmd/theone`
2. 配置 `theone.yaml` 中 `adapter.expand_mode: v2`
3. （可选）MCP `theone` 用于 Agent 主动 `memory_observe` / `memory_remember`

## 安装 Hooks

```bash
chmod +x scripts/install-claude-hooks.sh
./scripts/install-claude-hooks.sh
```

将生成 `.claude/settings.theone-hooks.json`。若已有 `.claude/settings.json`，用 `jq` 合并 `hooks` 段（见安装脚本输出）。

Hook 脚本路径使用仓库绝对路径；换机器后需重新运行安装脚本。

## 事件映射

| Claude 事件 | 脚本 | 行为 |
|-------------|------|------|
| `SessionStart` | `theone-session-start.sh` | `session.start` → ingest |
| `UserPromptSubmit` | `theone-user-prompt-submit.sh` | `prefetch-context` + `additionalContext` |
| `PostToolUse` | `theone-post-tool-use.sh` | `capture.atomic`（文件/工具） |
| `Stop` | `theone-stop.sh` | `turn.completed` |
| `SessionEnd` | `theone-session-end.sh` | `session.end` + 清理 runtime 缓存 |

绑定文件：`.theone-data/runtime-state/binding.claude_code.json`  
注入面：`.claude/theone-context.md`（同时经 `UserPromptSubmit` 注入上下文）

## 验收

```bash
scripts/acceptance/p4_claude_hooks.sh
```
